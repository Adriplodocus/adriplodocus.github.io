Pokémon Card Collection

Vibecoded
TypeScript Cloudflare Workers Hono D1 Vite Twitch EventSub Web Push

A Twitch channel-points minigame: viewers redeem rewards, gift subs, bits or donations to open packs of Pokémon cards and build their collection, with an album, trading, a marketplace, achievements and an OBS overlay that reveals each pack live on stream.

It runs on a Cloudflare Worker (Hono) with a D1 database, Twitch login and EventSub webhooks, PayPal payments, browser push notifications and an admin panel whose settings are editable from Google Sheets. Covered by tests on the Workers runtime.

Stream Counters

Vibecoded
TypeScript Next.js Cloudflare Pages D1 Twitch EventSub Electron

Counter manager for streamers (deaths, wins, attempts…) displayed live in OBS. Counters can be driven from the dashboard, chat commands, channel-point redemptions or a Stream Deck, and reset automatically when the stream starts.

Built with Next.js on Cloudflare's edge runtime and D1, with real-time updates via Server-Sent Events, a chat bot, automatic stream markers and clips, and a companion Electron desktop app for global hotkeys.

Try it out! (Web)
